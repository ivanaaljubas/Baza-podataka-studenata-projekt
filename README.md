# Baza podataka studenata – C projekt

Ovaj projekt je izrađen u programskom jeziku **C** i predstavlja jednostavan sustav za upravljanje bazom podataka studenata putem konzolnog sučelja. Projekt je razvijen kao praktična vježba programiranja i rada s datotekama.

## Funkcionalnosti
- Dodavanje novog studenta
- Prikaz svih studenata
- Pretraga studenta po imenu ili ID-u
- Brisanje studenta iz baze
- Ažuriranje podataka o studentu
- Spremanje i učitavanje podataka iz tekstualne/binarne datoteke

## Tehnologije i koncepti
- Programsko okruženje: C
- Rad s **strukturama (struct)** za pohranu studentskih podataka
- Korištenje **datoteka (file handling)** za trajnu pohranu podataka
- Manipulacija nizovima znakova i formatiranjem ispisa
- Korištenje petlji, uvjeta, funkcija i pokazivača
